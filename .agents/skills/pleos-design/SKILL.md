# 화면 설계 및 검증

`../pleos-connect/references/source-map.md`에서 9c1fe6a8475c(소개), e12e49cc3efc(레이아웃), 189d894e8124(window), 94caa75424dd(색상), 728dd6fe8092(타이포그래피)와 사용하는 컴포넌트 페이지를 읽는다. 모든 화면에 모든 컴포넌트를 적용하지 않는다.

- 공식 의무와 권장 표현을 유지한다. 장식/자동스크롤/애니메이션, 한손 조작, 짧은 인지시간을 주행 정책과 함께 검토한다.
- 원문 대비 기준 4.5:1, 지연 0.25초 초과 시 응답중 표시를 각각 측정/검증한다. 기본 Material 테마라고 충족 판정하지 않는다.
- 영어 문자/단어 수 기준을 한국어 글자수로 옮기지 않는다. 실제 언어별 규정과 3줄 제한을 원문 조건에 맞게 평가한다.
- 텍스트 mm 기준과 sp/px 권장은 다른 단위다. 디스플레이 물리정보 없이 상호 변환하거나 준수했다고 판단하지 않는다.
- Landscape/Portrait, split-window, 다양한 해상도·종횡비, IME resize 및 시스템 오버레이를 확인한다. Driving view/GNB 등 시스템 영역을 침범하지 않는다.
- 버튼의 상태(pressed/disabled/loading), 크기·간격·계층 및 터치 영역은 각 컴포넌트 원본 도해까지 확인한다. 이미지에만 있는 수치를 추측하지 않는다.
- 주간/야간 대비, 잘림/겹침, 긴 번역, 기능 비활성 상태, 입력 오류 상태를 실제 화면으로 검토한다.
- CCP 요구는 설치유형/계약별 조건을 확인한다(05666ca0cce1). 모든 사용자 설치 앱에 필수라고 일반화하지 않는다. 터치로 필수 기능 사용이 가능해야 한다.
- 알림/팝업/토스트 사용 시 각 페이지를 추가로 읽고 빈도·방해·광고 제한을 판정한다.

공식 Figma 리소스는 sources/9c1fe6a8475c.md의 다운로드 링크를 사용한다. UI 증거에는 디바이스/해상도/밀도/윈도 모드와 스크린샷을 기록한다. DES-* 규칙 및 각 원문 세부 항목을 작업 기록에 남긴다.
