Importing Vehicle SDK
Vehicle SDK 사용을 위해 SDK 의존성을 설정합니다. 퍼미션 설정은  [link: https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/Vehicle/vehicle-permission] Permission을 참조하세요.

Maven 저장소 등록​

SDK를 내려받을 Maven 저장소를 앱 프로젝트의 settings.gradle에 등록합니다.

Kotlin
Groovy
dependencyResolutionManagement {
    ...
    repositories {
        maven {
            url = uri("https://nexus-playground.pleos.ai/repository/maven-releases/")
        }
        ...
    }
}

dependencyResolutionManagement {
    ...
    repositories {
        ...
        maven {
            url "https://nexus-playground.pleos.ai/repository/maven-releases/"
        }
        ...
    }
}


SDK 의존성 추가​

앱 모듈의 build.gradle에 SDK 의존성을 선언합니다.

Kotlin
Groovy
dependencies {
    implementation("ai.pleos.playground:Vehicle:2.3.2")
}

dependencies {
    implementation "ai.pleos.playground:Vehicle:2.3.2"
}
