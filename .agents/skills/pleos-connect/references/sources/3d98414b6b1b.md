Anatomy​



1. Root : App bar 컴포넌트를 감싸는 최상위 컨테이너 영역 

2. Present Value : 현재 선택된 value를 보여주는 영역 

3. Next, Prev Value : 선택 가능한 value가 나열되어 보여지는 영역

 | Option | Value | Description
