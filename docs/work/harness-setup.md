# 하네스 구성

검증 결과 (2026-11-02): 스킬 4개 공식 quick_validate 통과. verify_harness 기본 검사 통과(133개 소스 해시/27개 규칙 문서 연결/Claude 공유 링크/정적 Manifest). 보고서 PASS→0, FAIL→1, NOT_TESTED→2, N/A→0 및 근거 누락→1을 임시 fixture로 검증했다. Studio MCP build_project 성공. 공식 validator의 PyYAML은 /tmp에만 설치했고 앱 의존성에는 추가하지 않았다.

요청: 루트에 AI 자동 진입점, Pleos 규정/디자인별 스킬과 구현-검증-수정 루프 구성.

참고한 두 UGC 레포에서 진입점/스킬/검증/핸드오프 구조만 참고했다. 업무 코드, 비밀 설정, 업무 지침은 복사하지 않았다.

검증 범위는 하네스 인벤토리·연결·Manifest 정적 확인 및 validator 동작이다. 수집된 133개 문서 전체의 제품 준수 판정은 수행하지 않았으며, 현재 앱의 디자인·실차·심사 적합성은 미검증이다. API 심볼 전체 미러링은 제외했고 공식 링크를 작업 시 확인하도록 했다.
