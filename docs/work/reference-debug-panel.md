## 백드롭 터치 회귀 수정

DES-06/08, DOC-904663536d42의 닫기 동작을 다시 확인했다. 전체 화면 Dialog 내부의 흰 영역 터치는 Window 바깥 터치로 전달되지 않는다. 흰 백드롭을 별도 하위 레이어로 배치하고 포인터 탭에서만 닫는다. 위에 놓인 비클릭 Material 3 Surface가 내부 빈 영역까지 하위 형제 레이어의 히트 테스트를 차단하고 자식 컨트롤은 기존 입력을 받는다. X와 시스템 뒤로 가기는 기존 경로를 유지한다. 백드롭에 클릭 접근성 노드를 추가하지 않았다.

좌표 계산을 추가하지 않았다. 실제 기준은 Compose 형제 레이어의 히트 테스트이며, 정적 회귀 테스트에서 해당 레이어 구조와 닫기 경로를 확인한다. 실제 렌더링과 기기 터치는 NOT_TESTED다.
